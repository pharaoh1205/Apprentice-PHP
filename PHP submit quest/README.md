「PHP/オブジェクト指向」の提出クエストです

### 概要
PHPでオブジェクト指向を用いてターミナル（CLI）で動作する戦争ゲームを作成しました。
ステップ５までの課題の問題文にあるように、下記の仕様で作成しました。

- プレイヤー人数は2~5人の選択式とする
- 各プレイヤーには名前を設定することができる
- 通常カード52枚＋ジョーカー1枚の計53枚でゲームを行う
- 開始時に親となった人はカードをよく切り、各プレイヤーに裏向きで均等に配る（この配られたカードを山札と呼ぶ）
- 「戦争！」の掛け声とともに、各プレイヤーは山札の一番上のカードを引いてオモテ向きに置く（このカードを場札と呼ぶ）
- 出したカードの強さの大小を比べて一番強いカードを出した人が勝ちとなり、全プレイヤーの場札をもらう。
- 勝者がとった場札は手元に置いておき、手札が0枚になった際によく切って山札に加える
- カードは強い方から、ジョーカー、A、K、Q、J、10、9、8、7、6、5、4、3、2 とする。ただし、Aが複数出た場合はスペードのAを引いたプレイヤーを勝利とする
- 一番強い数値が複数出た場合は、決着がつくまで勝者どうしで山札からカードを引き続ける。
- 誰かの手札がなくなった時点でゲームは終了とする。
- ゲーム終了時に持っているカードの枚数が多い順に1位、2位、・・・とランキング形式で成績が発表される。

※またファイルはステップごとに作成しておりステップの数字とファイル名の数字がリンクしています。
なので完成品はwar5.phpとなります。

### 実行手順

**ステップ 1: ターミナルの起動**

**ステップ 2: 作業ディレクトリの移動**
ターミナル上で以下の
"PHP submit quest”ファイルが格納されているディレクトリへ移動する。

**ステップ 3: プログラムの実行**
ディレクトリ移動後、以下のコマンドを実行してプログラムを開始する。
php war5.php

**ステップ 4. 入力プロンプトの操作手順**
プログラム起動後、画面に表示される指示に従い標準入力（キーボード入力）を行う。
